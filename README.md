# ia-que-pergunta-desenvolvimento-de-simulador
Este repositório documenta o processo de definição e análise de uma vaga de Analista de Automação e IA, incluindo entrevista simulada, plano de estudos e flashcards de apoio.   O objetivo é consolidar práticas de automação, engenharia de prompt e infraestrutura em VPS, além de registrar o desenvolvimento de competências técnicas e comportamentais.
